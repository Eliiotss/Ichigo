# materials/

Materi belajar pribadi — **terpisah dari kode aplikasi IchiGo**. Bukan bagian
dari dataset app; tidak dipakai saat build.

- `materi.md` — tabel kosakata rapi `| Kata | Bacaan | Arti | Contoh |`,
  hasil rapikan dari ekspor Anki (materi/konten saja, tanpa data teknis
  guid/HTML/audio). 12.376 kata unik (dedup kata+bacaan).
- `tidy_materi.py` — skrip pembuatnya. Perbarui dengan:
  `python3 tidy_materi.py "ekspor-anki.txt" materi.md`

Catatan: disimpan untuk keperluan belajar pribadi.
