# Logo source (vector)

`ichigo-mark.svg` is the standalone vector mark (enso + 一 + torii + stepping
stones) assembled from the user's Claude Design artifact "IchiGo Logo"
(pure-vector redesign). All launcher/splash/store assets are rendered from this
vector at high resolution — no screenshots.

- Launcher icon: `app/src/main/res/mipmap-*` + adaptive foreground
  `app/src/main/res/drawable-*/ic_launcher_foreground.png` (background cream
  `#FCF9F4`).
- Splash wordmark: `app/src/main/res/drawable-nodpi/ic_splash_logo.png`
  (mark + "IchiGo" in the Fredoka font; "Ichi" #1B2228, "Go" #E03A2C).
- Play Store listing icon: `ichigo-playstore-icon-512.png` (512×512).
